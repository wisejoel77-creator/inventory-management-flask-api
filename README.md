# Inventory Management System

A simple full-stack Inventory Management System built with React (frontend) and Flask (backend). The app allows users to add, view, update, delete, and search inventory items, as well as look up product information using a barcode.

---

## Features

- Add new inventory items
- View all inventory items
- Search items by barcode
- Update existing items
- Delete items
- External product lookup by barcode
- REST API communication between frontend and backend

---

## Tech Stack

### Frontend
- React (Vite or Create React App)
- JavaScript
- CSS

### Backend
- Flask (Python)
- Flask-CORS
- JSON-based API
